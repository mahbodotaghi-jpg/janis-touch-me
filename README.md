# NITRO Client (Fabric, MC 1.21.4)

Combat:  AutoTotem, AutoInvTotem, TotemOffhand, HoverTotem, AutoCrystal, AutoHitCrystal, CrystalOptimizer,
         AnchorMacro, DoubleAnchor, AutoJumpReset, ShieldBreaker, MaceSwap, ElytraSwap, Hitbox, NoHitDelay
Render:  StorageESP, PlayerESP, Freecam
World:   SchematicBuilder (open its GUI from the settings pane: 3D preview + material list)
Misc:    AutoTool, NameHider, SafeMode (on by default)

GUI (Right Shift): category rail | module list | settings pane.
